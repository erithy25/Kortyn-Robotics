# GPU-Messungen (Phase 5)

Hier liegen die Messdateien des GPU-Notebooks (`notebooks/gpu_benchmark.ipynb`), Format
`kortyn-gpu-benchmark-v2`. Hochladen im Browser: [`docs/gpu_benchmark_browser.md`](../../../docs/gpu_benchmark_browser.md).
Auswertung nach der präregistrierten Regel (`reports/phase5_preregistration.md`, Abschnitt 5):

```bash
uv run python -m kortyn.phase5_steps gpu-decision
```

*English:* measurement files of the GPU notebook go here; `python -m kortyn.phase5_steps gpu-decision` applies the
pre-registered decision rule to every file in this folder.
